# 拿到 report_docs 之後做的事

這個資料夾是我在 `reports_docs/`（11/20）之後補做的實驗與簡報製作檔。

## 一段話的版本

拿到 report_docs 之後，我先照 setup report 的協定從原始資料把管線獨立重建一次，global 與 stock 兩種模式的數字和報告最多差 0.005，確認主要結果重現得出來。接著補了報告沒有回答的四件事。第一，盤前 VIX 的 +0.059 是什麼：我加了三個對照組（收盤時就知道的 VIX、落後一天的缺口、在日期間打亂的缺口），只有預測當下才知道的缺口有效，所以增益來自時點，簡報裡把 16:00 與 03:15 兩個預測時點分開報告。第二，報告裡逐日 AUROC 幾乎不動，代表模型學到的是哪幾天會漲、不是哪些股票會漲：我加了一個兩參數的曝險模型（大盤訊號乘上個股與大盤的相關），同日排序從 0.509 到 0.532。第三，結論換個期間還成不成立：在資料集結束後的 192 個交易日做了一次前瞻測試，預期事先寫下、只評分一次，方向相同，VIX 的增益變小而且不顯著，曝險模型仍然成立。第四，和文獻比：RQ1 補了 Random Forest 與 XGBoost，並把三篇文獻的做法搬到我們的資料上重跑，其中一篇量級一致，另外兩篇的 baseline 都在五成附近、沒有重現論文的數字。這些補上之後，專案從「40 組配置的結果」變成一條接得起來的論證：收盤時點的上限在哪、盤前的增益從哪裡來、它能不能分辨個股、換個期間是否成立、和文獻對不對得上。你們的 40 組結果仍然是 RQ1 到 RQ4 的主體，我補的是對照、解釋與外部檢驗，簡報就是照這條線編的。

## 要重跑的話

腳本用相對路徑讀資料。把 `dataset/archive/NASDAQ100_Historical_Data.csv` 放到這個資料夾底下，和 `final_experiments/` 同一層，就能從 `00_build_panel.py` 開始跑。需要 Python 3.10 以上，以及 pandas、numpy、scipy、scikit-learn、lightgbm、matplotlib；`18` 另外要 xgboost，`20` 要 torch。

## 和報告不一樣的地方

- 面板是我重建的：429,882 列（報告 430,397），測試列 189,237（報告 184,061）。簡報上的主要數字用的是你們報告的版本，我的重建只用在新增的實驗。
- 沒有重建的：TALL 的 66 個額外指標、sector 與 cross 兩種策略。這三項簡報直接引用報告的數字。
- 相似度檢索的實驗沒有碰，放在簡報附錄第 41 頁，各組的說明是從報告欄位推的。

## 需要確認的事

1. Environment（第 23 頁）：硬體、作業系統、執行時間。
2. LightGBM 超參數（300 棵、31 葉 → 200 棵、7 葉）與分類門檻（0.5 → 訓練集上漲率）為什麼和 Progress 不同。
3. 產業分類的來源。
4. 相似度檢索要不要留在附錄，以及做這個實驗的動機。

## 限制

- 文獻重跑只能說「在我們的資料上沒有重現」，不能說論文有錯。論文沒寫的設定是我假設的（列在腳本開頭與簡報第 49、50 頁）；指標、標籤與管線都對過，但沒有先在他們的資料上重現原數字。
- Wang 等的 LSTM 只跑了一種設定、三個種子，在 CPU 上跑。
- 前瞻測試裡盤前 VIX 的增益不顯著。
- 曝險模型的形式是事後定的，前瞻測試是它唯一的獨立檢驗。
- 排行榜第 2 至 6 名（0.529–0.538）比我們的 T27 高 0.01 到 0.02，原因沒有查明。
